HTML Tutorial for Beginners: Complete Guide

By TechWithAmit | Beginner Tutorial

Want to build your first website? HTML is one of the best places to start. This guide explains HTML basics, common tags and useful examples in a simple step-by-step format.

HTML stands for HyperText Markup Language. It provides the structure of a webpage. CSS controls its appearance, while JavaScript can add interactive behaviour.

1. What Is HTML?

HTML is a markup language used to organise webpage content. It tells the browser which parts are headings, paragraphs, images, links, lists and other elements.

HTML is commonly used for:

  • Personal websites and blogs
  • Business websites
  • Article and documentation pages
  • Forms and structured webpage content
  • The foundation of web development projects
Remember: HTML creates structure, CSS styles the page, and JavaScript adds interactive behaviour.

2. Basic HTML Structure

Every normal HTML page starts with a document declaration, followed by the html, head and body elements.

Example:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport"
        content="width=device-width, initial-scale=1.0">
  <title>My First Website</title>
</head>
<body>
  <h1>Hello World!</h1>
  <p>This is my first webpage.</p>
</body>
</html>

What do these tags mean?

  • <!DOCTYPE html> declares an HTML document.
  • <html> contains the page content.
  • <head> contains metadata and page settings.
  • <title> sets the browser tab title.
  • <body> contains visible webpage content.
  • <meta> provides metadata such as character encoding.

3. Headings and Paragraphs

HTML provides six heading levels, from <h1> to <h6>. Paragraphs use the <p> element. 

<h1>Main Heading</h1>
<h2>Section Heading</h2>
<h3>Smaller Heading</h3>

<p>This is a paragraph of text.</p>

Use headings in a logical order so readers and search engines can better understand the organisation of your content. Do not choose heading tags only because of their default size.

4. Text Formatting in HTML

HTML includes elements for expressing emphasis and highlighting text. CSS can control the visual style. 

<strong>Important text</strong>

<em>Emphasised text</em>

<mark>Highlighted text</mark>

<small>Smaller text</small>

<p>Water formula: H<sub>2</sub>O</p>

<p>Math example: x<sup>2</sup></p>

Prefer <strong> for important content and <em> for emphasis when appropriate.

5. HTML Links

The anchor element <a> creates a clickable link. Its href attribute specifies the destination. 

<a href="https://example.com/">
  Visit Example
</a>

To link to another page in the same website:

<a href="about.html">
  About Us
</a>

Use meaningful link text so visitors know where a link will take them. Check that internal links point to pages that actually exist.

6. Adding Images in HTML

The <img> element displays an image. It uses the src attribute for the image location and the alt attribute for alternative text. 

<img
  src="images/logo.png"
  alt="TechWithAmit website logo"
  width="300"
>

Make sure the image path matches the actual filename and folder. Useful alternative text describes the image for people who cannot see it. Decorative images may use an empty alt attribute.

7. HTML Lists

Use an unordered list for items where order does not matter, and an ordered list when sequence is important.

Unordered list

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

Ordered list

<ol>
  <li>Create an HTML file</li>
  <li>Write your code</li>
  <li>Preview the webpage</li>
</ol>

8. HTML Tables

Tables organise data into rows and columns. Use table headings to make the information easier to understand. 

<table>
  <thead>
    <tr>
      <th>Language</th>
      <th>Purpose</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>HTML</td>
      <td>Structure</td>
    </tr>
    <tr>
      <td>CSS</td>
      <td>Styling</td>
    </tr>
  </tbody>
</table>

Use tables for tabular information, not to arrange the entire layout of a webpage.

9. HTML Forms

Forms collect information from users. HTML provides input fields, labels, buttons and other form controls. 

<form action="#" method="post">
  <label for="name">Your Name</label>

  <input
    type="text"
    id="name"
    name="name"
    required
  >

  <button type="submit">
    Submit
  </button>
</form>

This example demonstrates the HTML structure only. A real form needs an appropriate server or form service to process submissions. Never collect sensitive information without proper security.

10. Semantic HTML

Semantic elements describe the purpose of different page sections. They make the document structure easier for people and assistive technologies to understand. 

<header>Website header</header>

<nav>Navigation links</nav>

<main>
  <article>
    <h1>Article title</h1>
    <p>Article content goes here.</p>
  </article>
</main>

<footer>Footer content</footer>

Use these elements according to their meaning rather than choosing them only for their appearance.

11. Common HTML Beginner Mistakes

  • Forgetting to close elements that require closing tags.
  • Using an incorrect image or file path.
  • Leaving important images without useful alt text.
  • Using headings only to change font size.
  • Forgetting the mobile viewport meta tag.
  • Using the same ID more than once on a page.
  • Publishing links that lead to missing pages.
  • Assuming that HTML alone can process a server-side form.
Tip: Test your page in the browser and check that every link, image and important section works as expected.

12. Practice Project: Build Your First Webpage

Now use the concepts from this guide to create a simple personal webpage. You can add your own content and improve the design later. 

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport"
        content="width=device-width, initial-scale=1.0">
  <title>My First Webpage</title>
</head>
<body>

  <h1>Welcome to My Website</h1>

  <p>I am learning HTML.</p>

  <h2>My Interests</h2>

  <ul>
    <li>Technology</li>
    <li>Coding</li>
    <li>Learning AI</li>
  </ul>

  <a href="https://example.com/">
    Example Link
  </a>

</body>
</html>

Save this code as index.html in a separate practice folder, then open it in a browser or use your editor's preview. Do not overwrite your main TechWithAmit homepage.

13. Frequently Asked Questions

Is HTML easy for beginners?

HTML is a useful starting point because you can begin with a few basic tags and gradually build more complex pages.

Can I learn HTML on a phone?

Yes. A code editor and a mobile browser can help you practise HTML. A computer may be more convenient for larger projects, but it is not required to begin learning.

Is HTML a programming language?

HTML is a markup language. It describes the structure and meaning of webpage content rather than implementing general programming logic.

What should I learn after HTML?

Learn CSS next to style your pages, followed by JavaScript to add interactive behaviour.

Where can I find official HTML documentation?

The MDN Web Docs provide tutorials, references and examples. You can start with the official learning resource below.

Conclusion

HTML is the foundation of webpage structure. Start by learning headings, paragraphs, links, images and lists. Then practise tables, forms and semantic elements by building small projects.
