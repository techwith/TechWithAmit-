JavaScript Tutorial for Beginners

JavaScript ek popular programming language hai jo websites ko interactive banati hai. Iski help se buttons, forms, menus, calculators aur bahut saare useful features banaye ja sakte hain.

1. JavaScript Kya Hai?

HTML webpage ka structure banata hai, CSS uska design karta hai aur JavaScript webpage mein functionality add karta hai.

2. JavaScript Kaise Likhein?

JavaScript ko HTML ke script tag mein ya alag .js file mein likh sakte hain. 

<script>
  alert("Hello World!");
</script>

3. Variables

Variables data store karne ke liye use hote hain. JavaScript mein let aur const commonly use kiye jaate hain. 

let name = "Amit";
let age = 18;
const language = "JavaScript";

console.log(name);
console.log(age);
console.log(language);

4. Data Types

  • String: text, jaise "Hello"
  • Number: numbers, jaise 25
  • Boolean: true ya false
  • Array: values ki list
  • Object: related information ka collection
let city = "Chhindwara";
let marks = 70;
let isStudent = true;

let subjects = ["Maths", "Physics", "Chemistry"];

console.log(city);
console.log(subjects[0]);

5. Conditions

if aur else ka use condition ke according decision lene ke liye hota hai. 

let marks = 70;

if (marks >= 40) {
  console.log("Pass");
} else {
  console.log("Try again");
}

6. Loops

Loops kisi task ko multiple times repeat karne mein help karte hain. 

for (let i = 1; i <= 5; i++) {
  console.log(i);
}

7. Functions

Function reusable code ka block hota hai. Use zarurat padne par call kar sakte hain. 

function greet(name) {
  return "Hello " + name;
}

console.log(greet("Amit"));

9. DOM Kya Hai?

DOM ka full form Document Object Model hai. JavaScript DOM ke through webpage ke HTML elements ko access aur change kar sakti hai. 

document.getElementById("message").textContent =
  "JavaScript is working!";

10. JavaScript Kaise Seekhein?

  1. Variables aur data types practice karein.
  2. Conditions aur loops samjhein.
  3. Functions banana seekhein.
  4. DOM aur events par practice karein.
  5. Ek simple calculator ya quiz app banayein.
Beginner Tip: Code ko sirf copy-paste mat karein. Har example mein values change karke dekhein ki output kaise badalta hai.
