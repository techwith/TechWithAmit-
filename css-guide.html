CSS Tutorial for Beginners: Learn CSS from Basics

CSS ka full form Cascading Style Sheets hai. CSS ka use website ko attractive banane ke liye hota hai. HTML website ka structure banata hai, jabki CSS uska design improve karta hai.

1. CSS Kya Hai?

CSS se hum website ke colors, fonts, spacing, backgrounds, borders aur layout ko control kar sakte hain.

Ye ek CSS-styled example box hai.

2. CSS Syntax

CSS rule mein selector, property aur value hoti hai.

p {
  color: blue;
  font-size: 18px;
}
  • p: HTML paragraph ko select karta hai.
  • color: Text ka color set karta hai.
  • font-size: Text ka size set karta hai.

3. HTML Mein CSS Kaise Add Karein?

Inline CSS: HTML element ke andar style likhte hain.

<p style="color: red;">Hello World</p>

Internal CSS: HTML file ke head section mein style tag use hota hai.

<style>
  h1 {
    color: green;
  }
</style>

External CSS: Alag CSS file banakar HTML se connect karte hain.

<link rel="stylesheet" href="style.css">

Bade projects mein external CSS file use karna convenient hota hai.

4. CSS Colors and Background

body {
  background-color: lightgray;
}

h1 {
  color: navy;
}

Colors ke liye color names, HEX values aur RGB values use kar sakte hain.

5. Margin and Padding

  • Margin: Element ke bahar ki space.
  • Padding: Element ke content aur border ke beech ki space.
  • Border: Element ke around line.
.box {
  margin: 20px;
  padding: 15px;
  border: 2px solid black;
}

6. CSS Fonts

p {
  font-family: Arial, sans-serif;
  font-size: 16px;
  font-weight: bold;
}

7. Responsive Website Kya Hai?

Responsive website mobile, tablet aur computer ki screen ke according apna layout adjust karti hai. 

@media (max-width: 600px) {
  h1 {
    font-size: 24px;
  }
}

8. CSS Seekhne Ke Baad Kya Karein?

  1. HTML basics practice karein.
  2. CSS selectors aur box model samjhein.
  3. Flexbox aur CSS Grid seekhein.
  4. Ek responsive personal website banayein.
  5. JavaScript basics seekhna shuru karein.
Beginner Tip: Har example ko apne code editor mein try karein. Sirf code padhne ke bajay khud practice karne se concepts achhe se samajh aate hain.
