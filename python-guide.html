Python Tutorial for Beginners: Learn Python from Zero

Python ek popular programming language hai. Iska syntax beginner-friendly hai aur iska use web development, automation, data analysis, AI aur machine learning mein hota hai.

1. Python Kya Hai?

Python ek high-level programming language hai jise simple aur readable code likhne ke liye design kiya gaya hai. Beginners ise programming seekhne ke liye use kar sakte hain.

2. Python Ka First Program

Python mein text display karne ke liye print() use hota hai.

print("Hello World!")
print("Welcome to Python")

3. Variables

Variable ek naam hota hai jisme hum data store kar sakte hain. 

name = "Amit"
age = 18
course = "B.Tech CSE"

print(name)
print(age)
print(course)

4. Python Data Types

  • String: text, jaise "Hello"
  • Integer: whole numbers, jaise 25
  • Float: decimal numbers, jaise 7.5
  • Boolean: True ya False
  • List: multiple values ki collection
name = "Amit"
marks = 70
percentage = 70.5
is_student = True

print(type(name))
print(type(marks))
print(type(percentage))
print(type(is_student))

5. User Se Input Lena

input() function user se information leta hai.

name = input("Enter your name: ")
print("Hello", name)

6. Conditions: if and else

Conditions ki help se program decision le sakta hai. 

marks = 70

if marks >= 40:
    print("Pass")
else:
    print("Try again")

Python mein indentation yani line ke starting spaces important hote hain.

7. Loops

Loop kisi instruction ko baar-baar run karne mein help karta hai. 

for i in range(1, 6):
    print(i)

8. Lists

List mein multiple values ek saath store ki ja sakti hain. 

subjects = ["Maths", "Physics", "Chemistry"]

print(subjects[0])
print(subjects[1])

subjects.append("Programming")
print(subjects)

9. Functions

Function reusable code ka block hota hai. 

def greet(name):
    print("Hello", name)

greet("Amit")
greet("Student")

10. Python Kahan Use Hoti Hai?

  • Artificial Intelligence aur Machine Learning
  • Data analysis
  • Automation scripts
  • Web development
  • Education aur scientific computing

11. Python Kaise Practice Karein?

  1. Variables aur data types samjhein.
  2. Input, conditions aur loops practice karein.
  3. Lists aur functions seekhein.
  4. Simple calculator banayein.
  5. Chhote projects bana kar practice karein.
Beginner Tip: Code ko khud type karke run karein. Error aaye toh use samajhne ki koshish karein; debugging bhi programming ka important part hai.
